# SentryLoom v0.16.12 and HQ v0.4.6

This reliability release adds a clear, acknowledged device-offboarding path
and prevents optional Windows telemetry failures from taking down the local
dashboard.

## Highlights

- Offboard Windows, Linux, macOS, and Android endpoints from HQ.
- Offline offboarding remains queued and completes when the endpoint returns.
- The endpoint acknowledges the command before deleting its encrypted HQ
  credential; HQ then revokes the corresponding bearer token.
- Existing revoke-and-re-enroll behavior remains available for credential
  rotation.
- DNS, firewall, and USB status failures degrade to explicit unavailable states
  without breaking the rest of the dashboard.
- CI validates Node.js on Windows, Ubuntu, and macOS plus Android lint, tests,
  compilation, APK assembly, secret scanning, and public CodeQL analysis.

## Packages

- `SentryLoom-Setup-0.16.12.exe`
- `SentryLoom-HQ-Setup-0.4.6.exe`
- `SentryLoom-v0.16.12-SHA256SUMS.txt`

The Windows packages are unsigned development builds. Verify their SHA-256
checksums before installation. No signing key or credential is included.
