# SentryLoom v0.17.0 + HQ v0.5.0

This release adds managed lost-device response, removable-storage control, and
data loss prevention without changing the default behavior of existing
installations.

## Lost-device response

- Lock enrolled Windows, macOS, Linux, and Android endpoints remotely.
- Factory-wipe Android Enterprise Device Owner devices after an acknowledged,
  explicitly confirmed HQ command.
- Wipe company data on desktops only from exact administrator-configured roots;
  filesystem roots, the user profile, system paths, and the application working
  directory are rejected.

## Storage and DLP

- Block removable storage on individual Windows endpoints while leaving
  non-storage USB peripherals operational.
- Notify the endpoint user and HQ when USB storage is detected.
- Require labels for new documents: Public, Internal, Confidential, or Super
  Confidential.
- Deny Super Confidential transfers at monitored email, internet, and external
  storage integration gates unless the destination is explicitly allowlisted.

Browser and mail products must call the authenticated local DLP transfer gate
before transmitting a monitored file. SentryLoom does not claim to intercept
traffic that an integration does not submit to that gate.

## Safety

Remote wipe actions require the administrator to type the selected device name,
are capability-negotiated, acknowledged before execution, and recorded in both
endpoint and HQ audit history. Existing installations retain their prior policy:
DLP labeling is opt-in and no company-data wipe roots are configured by default.
